# StackUp Hold'em Heroes — UI specification

Consolidated on 2026-08-29.

## Global visual system
- Main title `STACKUP HOLD'EM HEROES`: 16px and no structural border.
- Titles: 16px.
- Subtitles/labels: 14px.
- Remaining text, inputs and buttons: 12px.
- No third typography size for ordinary UI text.
- Spacing between cards: exactly 6px vertically and horizontally.
- Structural containers/wrappers/sections must not have border, outline or box-shadow.
- Only functional/individual cards and useful buttons keep borders.
- Idle/non-selected functional cards: very light pastel-green treatment.
- Selected/active/current cards: strong green, same visual family as the primary Analyze Hand/action buttons, with active border/glow.
- Disabled controls: reduced opacity.
- Rounded corners remain consistent.

## Borders to remove
- External/structural BOARD wrapper border.
- External/structural PLAYERS wrapper border.
- External/structural REPORTS/HISTORY grouping border.
- Preserve borders on useful inner cards only, including player cards, participant cards, DNA history items/report cards and the inner BOARD card.

## Hand Analysis
- Hand History and Configuration cards must NOT be sticky/fixed to the top; they scroll normally with the page.
- Pre-flop card follows the same visual standard as the other cards.
- Analyze Play / Analyze Hand actions follow the same primary green action-button standard.
- Continue Analysis in Player DNA follows the same primary green action-button standard.
- Add participant / add action / DNA primary actions use the same highlighted green action pattern.
